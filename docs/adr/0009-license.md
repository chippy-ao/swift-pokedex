# ADR-0009: ライセンス

- ステータス: 承認済み
- 日付: 2026-10-28

## コンテキスト

リポジトリを公開するので、コードの再利用条件を決める必要があります。一方で、アプリが表示するポケモンの名前や画像は開発者の著作物ではなく、PokeAPI から実行時に取得するものです。

## 決定

- コードのライセンスは MIT とします。リポジトリのルートに `LICENSE` を置きます。
- 著作権表示は `Copyright (c) 2026 Daichi Aoki` とします。
- README に、ポケモン関連の権利は各権利者に帰属し、MIT の対象外であることを明記します。

## 理由

- MIT は条件が「著作権表示とライセンス文を残すこと」だけで、学習用のコードを気軽に参考にしてもらえます。
- ライセンスで許諾できるのは自分が権利を持つものだけです。ポケモンの名前や画像は MIT で許諾できないため、README で範囲を明示して誤解を防ぎます。
- 画像やデータはリポジトリに含めず実行時に取得するため、リポジトリの中身はすべて MIT で配布できます。

## 検討した代替案

| 案 | 不採用理由 |
| --- | --- |
| ライセンスを付けない | 公開しても再利用の条件が分からず、参考にしてもらいにくい |
| Apache-2.0 | 特許条項などが手厚いが、個人の学習用プロジェクトには MIT で十分 |
| MIT の LICENSE だけを置く | ポケモン関連のものまで MIT で許諾していると誤解される余地が残る |

## 影響

### 良い点

- 再利用の条件が明確になる。
- MIT の対象とそうでないものの境界がはっきりする。

### 悪い点・注意点

- ポケモンの画像やデータをリポジトリに含める変更(テスト用フィクスチャなど)をするときは、権利と MIT との関係を確認する。
